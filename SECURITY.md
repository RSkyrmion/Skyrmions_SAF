# Política de segurança

Não publique vulnerabilidades, credenciais expostas ou dados pessoais em uma issue aberta.

Use a opção **Security → Report a vulnerability** deste repositório para fazer um relato
privado ao mantenedor. Inclua apenas o necessário para reproduzir o problema e remova tokens,
chaves e outros segredos do exemplo.

Problemas científicos, erros de documentação e falhas de reprodução que não envolvam
segurança podem ser relatados pelas issues comuns.
